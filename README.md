# Link Saver 🔗

A simple Chrome extension to save your favourite links and access them whenever you need.

**A little heads-up:** This extension isn't published on the Chrome Web Store (aba paisa ta xaina deploy garna 😭), but you can still download the project and use it yourself. Here's how:

### How to install

1. Download this repository (click **Code → Download ZIP**) and extract it.
2. Open Chrome and go to `chrome://extensions`.
3. Enable **Developer mode** (top-right corner).
4. Click **Load unpacked**.
5. Select the extracted **Link Saver project folder** (the one containing `manifest.json`).

And that's it! You'll find Link Saver in your Chrome extensions. Pin it if you want quick access.

### Features

- Save your favourite URLs.
- Prevent duplicate links.
- Validate URLs before saving.
- Clear all saved links.
- Links stay saved even after closing Chrome.
